OPTIONAL PERSONAL MUSIC
=======================

The site works without a music file: its music button creates a soft ambient progression with the browser's Web Audio API.

To use a song instead:
1. Place an MP3 in this folder, for example our-song.mp3.
2. In assets/js/script.js, set CONFIG.musicSource to 'assets/music/our-song.mp3'.
3. Start playback by clicking the music control. Browsers do not allow audio to start before a visitor interacts with the page.

No track is bundled here; add only music you have permission to use.
